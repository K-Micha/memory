# Memory Game

A responsive memory game built with **HTML, SCSS, TypeScript and Vite**.

## Features

* Two-player memory game
* Selectable starting player
* Multiple board sizes (16, 24, 36 cards)
* Theme selection with hover preview
* Score tracking
* Winner and draw screens
* Confetti winner animation
* Responsive design for desktop and mobile
