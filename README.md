# Memory Game

A responsive memory game built with **HTML, SCSS, TypeScript and Vite**.

## Features

* 1 or 2 player mode
* Multiple board sizes (16, 24, 36 cards)
* Theme selection
* Score tracking
* Winner and draw screens
* Responsive design for desktop and mobile

## Technologies

* HTML5
* SCSS
* TypeScript
* Vite

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
